# system logos

one svg per system, `<id>.svg`, ids from `systems.json`. single color on transparent, any viewBox: the app masks them (`mask-image`), so they take whatever color the system is. same folder for emulator logos (`dolphin`, `pcsx2`, `duckstation`, `xemu`, `xenia`, `retroarch`).

**simple-icons marks** (CC0, https://github.com/simple-icons/simple-icons): gc, wii, wiiu, switch, 3ds, ps1, ps2, ps3, psp, vita, xbox, pc, retroarch, dolphin. logos are trademarks of their owners. wide wordmarks (ps2/ps3/psp/vita/wii/wiiu) have had their viewBox tightened to the ink — they ship in a 24×24 box and were rendering as 4px slivers under `contain`. `npx electron scripts/tighten-viewbox.js` does that measurement; rerun it if you drop in a new simple-icons file.

**drawn badges** (n64, snes, nes, gb, gba, ds, x360, dc, genesis, saturn, arcade, pcsx2, duckstation, xemu, xenia): generated by `node scripts/make-badges.js` from a small path-glyph set on the REPRO wordmark grid (cap 100, stem 22, bar 18). not fonts, so they render the same on every machine. edit the glyphs or word list there, not the svgs — or drop a real mark with the same name and remove the id from the script.

**proof sheet:** `npx electron test/logosheet.js` → `sketches/logo-sheet.png`. every logo at the three sizes the app uses (sidebar 36×18, banner 70×22, couch hero 50×16) in its system color. look at it before shipping a new mark.

add a system: `systems.json` in the repo root + a `<id>.svg` here.
