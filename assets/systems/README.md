# system logos

svgs from simple-icons (CC0, https://github.com/simple-icons/simple-icons) where one exists: gc, wii, wiiu, switch, 3ds, ps1, ps2, ps3, psp, vita, xbox, pc, retroarch, dolphin, sega marks. logos are trademarks of their owners.

where simple-icons has no mark (n64, snes, nes, gb, gba, ds, x360, dc, saturn, genesis, arcade) it's a plain text badge. replace with a better svg by dropping a file with the same name.

add a system: `systems.json` in the repo root + a `<id>.svg` here.
